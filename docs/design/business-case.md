# Business Case — CyberGuide

## 1. Problem / Opportunity
Small organizations and IT support teams often have cybersecurity guidance spread across multiple websites, documents, and bookmarks, which can slow down the process of finding a clear response to a security issue. There is an opportunity to organize common cybersecurity threats and response guidance in one simple web application.

## 2. Proposed Solution
CyberGuide will be a web application that presents a collection of common cybersecurity threats and security topics, such as phishing, weak passwords, malware, unsafe links, and account compromise. A user will be able to select a topic from the collection to open a detailed view with a short description, warning signs, recommended actions, and prevention tips. The application can also include a simple bookmark or pin feature so users can quickly return to important topics.

## 3. Options Considered

| Option | Description | Pros | Cons |
|--------|-------------|------|------|
| Option A | Continue using separate websites, notes, and bookmarks for cybersecurity guidance. | No development cost and users can keep using familiar resources. | Information remains scattered, takes longer to find, and may be inconsistent. |
| Option B (recommended) | Develop CyberGuide as a focused web application using the provided application template. | Centralizes information, fits the collection/detail design, is simple to prototype, and creates a portfolio project related to cybersecurity. | Requires initial development time and ongoing maintenance of the content. |

## 4. Feasibility

| Type | Assessment |
|------|------------|
| Operational — will people actually use/support this? | High. The application is designed for a simple task: finding a security topic and viewing clear guidance. The collection/detail layout should be easy for students, employees, or small IT teams to understand. |
| Technical — can we build it with what we have/can get? | High. The project can be built by adapting the existing web application template and using a small simulated data set. It does not require authentication or an external database for the prototype. |
| Economic — does the payoff justify the cost? | High. Development and hosting costs are relatively low, while the application can save time by reducing repeated searching for common cybersecurity guidance. |
| Schedule — can it be done in a useful timeframe? | High. The concept stays close to the provided template, which reduces technical complexity and makes a functional prototype realistic within the course schedule. |

## 5. Costs & Benefits

**Costs** (one-time + ongoing):

| Item | One-time | Ongoing/year |
|------|----------|----------------|
| Initial design and development (estimated 40 hours at $30/hour) | $1,200 | — |
| Basic hosting/domain allowance | — | $120 |
| Content review and maintenance (estimated 12 hours at $30/hour) | — | $360 |
| **Total** | **$1,200** | **$480/year** |

**Benefits** (tangible + intangible):

| Benefit | Tangible ($/time saved)? | Notes |
|---------|-----------------------------|-------|
| Reduced time spent searching for common cybersecurity guidance | $2,100/year | Estimate of 70 hours saved per year at $30/hour. |
| Reduced duplicate support/research effort | $600/year | Estimate based on avoiding repeated searches and explanations for common issues. |
| More consistent cybersecurity guidance | Intangible | Gives users one organized location for basic response and prevention information. |
| Better security awareness | Intangible | Can help users recognize common threats and respond more consistently. |
| Portfolio value | Intangible | Demonstrates web development, systems design, and cybersecurity interests in one project. |

**Estimated annual tangible benefit:** $2,700

**Payback period:** Approximately 6.5 months. The initial $1,200 development cost is recovered through an estimated monthly net benefit of about $185 after ongoing costs.

**First-year ROI:** Approximately 60.7%

ROI = ($2,700 benefit − $1,680 first-year total cost) / $1,680 first-year total cost = 0.607, or about 60.7%.

## 6. Priority & Urgency
Cybersecurity information continues to grow, and users regularly need quick guidance for common threats such as phishing, suspicious links, compromised accounts, and malware. Developing the application now provides a manageable way to organize this information while also creating a project that can be expanded later. If the project is delayed, users continue relying on scattered resources and the opportunity to build a useful cybersecurity-focused portfolio project is lost.

## 7. Recommendation
Proceed with Option B and develop CyberGuide as a collection-and-detail cybersecurity guidance web application using the provided template.
